# Aevora

Aevora 是运行在 Windows 上的 Personal AI，既可以作为伙伴、朋友和 cyber companion，也能帮助处理实际事务。同一个 Agent 保持人设和表达方式，记住背景与偏好，在对话中承接工作、保留进展和反馈，并通过语音、主动提醒和桌面 Orb 与你保持联系。

**下载源码，本机运行**。核心数据保存在本机；使用云端模型或语音服务时，需配置自己的服务账号，并确认相应数据范围和用途。

## 可以做什么

| 能力 | 使用方式 |
|---|---|
| 对话与长期记忆 | 与同一个 Agent 交流；审核、纠正、遗忘或删除记忆，按需召回当前背景 |
| 通用工具与资料协作 | 选择目录与文件，让 Agent 按观察动态组合文件／目录、受控命令、搜索／网页工具；具体变更和命令经审阅批准 |
| 有界持续工作 | 从目标建立有依赖、时间／文件条件的计划，在授权期限、资源与累计预算内推进；可暂停、撤权并跨重启续办 |
| 反馈与非参数学习 | 从交流或工作反馈提出可复用方法，经评价、显式采用或有限单次试用后使用；可保留、修订、停用或回滚 |
| 主动帮助与约定 | 对选定目标授权观察、判断和通知；可按目标暂停／恢复，也可建立单次时间约定 |
| 语音与 Presence | 麦克风输入、修改转写、朗读和停止；收起主窗口后通过 Orb 查看状态或快速交流 |

对话是主要工作空间。消息中的“查看任务与产物”会打开右侧对应事项；跨会话或独立事项可从“所有事项”管理。左右分隔线支持拖动、方向键调整和双击复位。

本次源码更新接通 Identity、Memory、Agency、Presence 与 Evolution 五支柱：相关人设、记忆与明确策略版本进入实际工作；工作结果可回到原会话，值得保留的经历经确认进入 Memory。普通伙伴交流有独立价值，不要求建立 Task 或 Goal。

## 快速开始

### 1. 准备环境

使用 Windows x64，并安装：

- Git、uv、Node.js／npm。
- Rust MSVC 工具链，Rust 至少 1.91。
- Visual Studio C++ Build Tools，包含桌面 C++ 工作负载和 Windows SDK。
- Microsoft Edge WebView2 Runtime。

Python 使用 3.12，由 uv 管理，并安装到项目的 `.venv`。安装工具后重新打开 PowerShell，确认 `git`、`uv`、`npm` 和 `cargo` 可以运行。

### 2. 获取源码并启动

在 PowerShell 中执行：

```powershell
git clone https://github.com/Lelov093/Aevora.git
Set-Location Aevora
.\scripts\setup.ps1
.\scripts\start.ps1
```

`setup.ps1` 按锁文件安装依赖并生成共享协议类型；任一步失败会停止。`start.ps1` 构建并打开桌面程序。首次安装与 Rust 构建需要联网下载依赖，耗时取决于设备与网络。

如果 PowerShell 阻止执行脚本，可只为当前终端放开执行策略，再运行上述脚本：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

没有 API Key 也能启动、创建本地 Agent 和查看本地数据。云端对话、资料生成、记忆提取／召回、方法生成／评价及语音需要各自的配置与授权。

### 3. 配置自己的服务

1. 首次打开时创建 Agent，填写身份描述和表达风格。
2. 在“设置 → 模型与连接”填写兼容 OpenAI Chat Completions 的地址、模型与 API Key，并允许对话用途。
3. 在“设置 → 记忆与召回”按需配置提取与召回。它们有独立用途和预算，不因允许对话而自动启用。
4. 需要语音时，在“设置 → 语音”配置北京地域的百炼业务空间 ID、ASR／TTS Key，并分别确认识别和朗读。

Key 由 Windows Host 使用当前用户的 DPAPI 保存，界面仅显示遮罩。也可参考 [.env.example](.env.example) 配置新数据目录首次启动时的导入；已有凭据不会被后来修改的 `.env` 覆盖。通常优先使用设置页面。

语音当前支持 `qwen-audio-3.1-asr-flash-streaming` 和 `qwen-audio-3.1-tts-flash`，后者使用 `longanhuan_v3.1` 音色。免费额度属于你自己的账号：需在服务商实际开启“免费额度用完即停”，并填写自己的截止日。Aevora 在该日期的北京零点停止 TTS；日期为空不能授权朗读，不会自动改为付费。

## 日常使用

- **普通交流**：直接发送文字，或按住语音按钮说话、检查转写后发送。普通交流无需建立目标。
- **通用事务**：从对话建议或“查证或处理…”沿用需求，选择目录／文件、读写与出站范围。Agent可列举、搜索及读取文本，提出新建、精确修改、建目录、复制／同根移动或受控脚本方案；具体变更与命令按现有流程审批。可选任务级新建／复制预授权，默认不覆盖已有文件。命令运行于当前Windows用户权限下，工作目录不是操作系统沙箱。
- **固定文件报告**：旧入口继续支持明确选定的 UTF-8 txt／md、新建输出；最多 8 个输入、2 份产物、16 个步骤。可查看完整正文，再批准保存，已有输出不覆盖。
- **持续推进**：在“所有事项→目标→让Agent持续推进”确认期限、资源、用途和累计预算，可选择一个已采用且适用的协作策略与返回会话；先生成并审阅计划，再按依赖、时间和本地文件条件推进。暂停、恢复或撤权沿该工作控制；单个工作暂停与Runtime暂停分别表达。退出期间保留状态，重新启动后仅在仍有效授权内继续。
- **接着交流**：在右栏“本次资料”回看目标或当前对话最多8项任务／8项执行及反馈，确认后用于后续回复，超出范围会提示遗漏。长期执行按节点依赖排列，独立工作分别记录；NeedsRevision原稿可在本机展开，不随该工作投影发送。其他模型报告可能含名称／路径，不额外读取原文件正文。目标选择作为本机线索保存，重启后重新确认资料；资料或模型配置改变也需要重新确认。
- **保留经历**：已完成回复的“记住／纠正理解…”可保存经你确认的事实、偏好或共同经历，后续可修订／遗忘／删除；工作来源可返回相应Task／Run。模型报告是关联证据，不自动变成用户事实。临时状态遵循有效期及会话范围，当前明确要求优先于旧偏好。
- **记录反馈与方法**：在任务中保存实际反馈，再查看适用方法并决定保留或修订。方法生成、评价和采用有独立控制，重要变化可回滚。
- **主动帮助**：在设置中选择目标，分别允许观察、判断与通知，并设置安静时段和预算。目标详情及目标选择器可暂停／恢复提醒；“需要时我自行联系”等短请求只提供确认入口，选定目标并确认后生效。恢复不会自动开启全局授权；单次约定和独立任务按原规则保留。
- **Orb**：在“设置 → Presence 与运行”开启。拖动移动、点击展开；可关闭或复位位置，查看生成／执行、等待、需处理及暂停状态并返回实际工作。Live2D 默认关闭。

关闭主窗口会收起到托盘，后台仍可能按已有授权运行。要真正退出，请从托盘或“设置 → Presence 与运行”选择**退出 Runtime**。后台暂停状态跨重启保留，前台回复、任务与语音有各自的停止操作。

## 数据与更新

本机数据默认位于项目 `.data`，包含身份、对话、记忆、任务和授权记录；依赖与构建缓存位于 `.venv`、`apps/desktop/node_modules` 和 `.cache`。外部选定文件与产物由你管理。

更新前：

1. 正常退出 Runtime。
2. 备份整个 `.data` 和自己的 `.env`（若使用），保持私有。
3. 执行 `git pull --ff-only`，重新运行 `setup.ps1` 和 `start.ps1`。
4. 核对原 Agent、历史和待处理工作。

当前数据库版本为 schema21。升级时按版本事务迁移，保留身份、Memory、任务、反馈与用量，不自动恢复出站确认，也不将任务完成改成目标达成；旧源码不能直接打开更高版本的数据。回退需配套使用更新前备份。DPAPI 凭据与 Windows 用户／机器有关，换机器后应重新填写 Key。

使用多个副本时，可通过 `AEVORA_DATA_DIR` 指定独立数据目录。不要上传 `.data`、`.env`、API Key 或私人资料。

## 当前边界

- 文本工具面向UTF-8文本，**目前不直接读取 PDF**。Office相关实现保留，未作为本次主线，也不代表完整跨应用自动化。
- 非参数学习涵盖资料准备／更新、沟通及协作方法；评价、采用、单次试用与回滚各有明确控制。不同方法的适用范围和收益分别判断，不宣称通用 RSI 或持续因果改善，不进行参数训练或任意自改产品代码。
- 长期工作仅在Host／Core运行时推进；不提供关机执行、云端常驻或无限授权。两Task依赖、条件等待与重启续办已有实际接合验证，不等于任意目标均能自主完成。
- 联网研究属于实验功能，支持受限公开 HTTPS HTML／文本；不支持登录页面、浏览器脚本、PDF／附件和递归抓取，需要审阅结果与来源。
- 模型建议与正文可能出错，可补充信息、指出问题并继续纠正，也可编辑、拒绝或重新准备。系统提供上下文、反馈、工具及权限机制，不承诺所有任务首轮全部符合预期。任务完成／文件保存成功不代表内容正确、目标达成或学习有效。
- 使用云端服务可能消耗额度；用途和预算由用户控制，模型不能授予文件或网络权限。
- 当前为源码运行初版，没有独立安装器、自动更新、跨设备同步或实时全双工语音。

## 源码结构

```text
apps/desktop/       React 界面与 Rust／Tauri Host
services/agent/     Python Core、状态与 SQLite 逻辑
packages/protocol/  Host 与 Core 的共享命令协议
scripts/           依赖准备、启动与协议生成
```

技术栈为 Tauri／React／Rust Host／Python Core／SQLite。路径、凭据与权限由 Host 掌握，模型负责建议与内容生成。修改共享命令后使用 `scripts/generate_protocol.py` 更新 TypeScript 定义。界面开发可使用 `.\scripts\start.ps1 -Dev`。

此仓库提供运行源码与使用说明；内部计划、验收材料、运行数据和凭据不随源码分发。源码构建及空白无Key启动已有本地检查，未声称覆盖全部Windows设备、原生多屏操作或所有任务内容质量。
